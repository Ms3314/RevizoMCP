Importing problems

Bulk-add problems by uploading a CSV on the import page. Your file can have any columns in any order — Revizo picks out only the fields it tracks and ignores everything else.

The default template

The simplest starting point is the sample CSV — grab it here: download sample CSV. It looks like this: 

Problem,Link,Difficulty,Topics,Description
Two Sum,https://leetcode.com/problems/two-sum/,easy,"arrays, hashing",Find two numbers that add up to the target.
Coin Change,https://leetcode.com/problems/coin-change/,medium,dp,Fewest coins to make up an amount.

Only Problem and Link are required — everything else is optional. You can add, remove, or reorder columns freely; Revizo will match by header name.

Recognized columns

Header names are matched case-insensitively; any of these synonyms work:

FieldAccepted headersRequiredWhat it's for
Problemproblem, title, problem name, namerequiredThe problem's name — used as the unique ID in your tracker. If you import the same title twice, the second is counted as a duplicate and skipped.
Linklink, problem link, url, problem urlrequiredWhere to find the problem — LeetCode, Codeforces, a PDF, whatever. Clicked from the dashboard.
Difficultydifficulty, leveloptional · defaults to mediumDrives the spaced-repetition ladder: easy problems get longer intervals, hard ones get shorter. Accepts easy, medium, hard.
Topicstopics, topic, subtopic, tagsoptionalComma-separated tags like arrays, dp, greedy. Used to filter the dashboard and to surface weak spots ("you keep failing on greedy").
Descriptiondescription, problem statement, notes, approachoptionalWhat the problem asks, constraints worth remembering, or your approach. Shown by the coach when the problem comes up for revision.

The rules

  • A row without both a problem and a link is skipped — you'll get a summary telling you exactly which rows and why.
  • Problems already in your tracker are counted as duplicates and left untouched (no overwriting).
  • Extra columns — Step, Starred, Notes, whatever — are simply ignored.
  • Files up to 1 MB / 5,000 rows per upload; split bigger lists.

Real-world example: importing a Notion export

If you've been tracking problems in Notion (like the Striver A2Z sheet), your export probably has columns like Problem, Approach, Description, Difficulty, Key insight, Last revised, Link, Mistakes, Notes, Problem ID, Solved, Starred, Step, Step no, Sub-step, Sub-step progress, Subtopic, Topic. Revizo will automatically pick out Problem, Link, Difficulty, Topic / Subtopic, and Description — everything else is ignored.

What happens after import

Imported problems start as unsolved backlog items. They'll appear in your dashboard immediately, and you can record attempts against them via the MCP tools (or ask your coach "mark Two Sum as solved"). The spaced-repetition schedule kicks in once you record your first attempt.
