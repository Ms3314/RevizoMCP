Import your full LeetCode history

The regular LeetCode sync uses public profile data and imports recent activity. To import all solved problems, connect your LeetCode account once with its LEETCODE_SESSION cookie.

1. Find your session cookie

  1. 1. Sign in to leetcode.com in your browser.
  2. 2. Open Developer Tools (usually F12 or right-click → Inspect).
  3. 3. Open the Application tab in Chrome/Edge (or Storage in Firefox), then open Cookies → https://leetcode.com.
  4. 4. Find LEETCODE_SESSION and copy its Value. Copy only the value, not the cookie name or other cookie fields.
This cookie is a private sign-in credential. Never paste it into an AI chat, share it with anyone, or include it in a screenshot.

2. Save it in Revizo

  1. 1. Sign in to Revizo and open LeetCode import settings.
  2. 2. Enter your LeetCode username and paste the cookie value into the session-cookie field.
  3. 3. Select Save connection, then choose Import all problems.

Revizo encrypts the cookie before saving it. You add it once; it is reused for future imports and is not sent through your MCP chat. If LeetCode expires the cookie, replace it in the same settings page. You can remove it there at any time.

The first import checks your solved-problem list. Later imports compare your solved count and only add slugs that are new since the last import. Existing tracker history is preserved.

LeetCode's solved-problem list does not include each problem's original solve date or older attempt history. Imported problems start their revision schedule on the import date; use the regular recent sync to bring in recent attempts.
