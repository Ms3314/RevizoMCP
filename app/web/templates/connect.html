Claude Desktop

Any other MCP client

Point the client at {{ mcp_url }} using the Streamable HTTP transport. The server advertises standard OAuth metadata, so auth-capable clients discover the sign-in flow automatically and no token setup is needed.

First steps once connected

Open your tool, sign in, and try:

  • “what should I revise today?” — your due list, with your past mistakes attached.
  • “sync my leetcode, user <your-id>” — pull in your real solves and recent failed attempts.
  • “record that as solved” — honest record, the problem climbs its ladder.
Everything (SRS state, mistakes, weak points) is private per signed-in account. Details in the README.
